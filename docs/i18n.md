# Languages

- Texts live in `src/shared/i18n/de.ts` and `en.ts`. Code calls `t('key', { placeholder })`,
  plurals go through `tp('key', count)` with the variants `.one` and `.other`.
- Static texts in `index.html` carry `data-i18n` (text content) or
  `data-i18n-attr="attribute:key; …"`.
- A unit test checks that every language has exactly the same keys and placeholders.
- The setting is stored in `config.json` (browser mode: `localStorage`, test override `?lang=en`).
  A change reloads the window; the native menu is rebuilt at once.
- Right to left: `dir` on `<html>` follows the language, the CSS uses logical properties
  (`margin-inline-start` and so on). A new language only needs one more file in `i18n/`.
